# ECLAT Beauty Tools

موقع متجر عربي RTL في ملف واحد فقط. ملف `index.html` يحتوي على HTML وCSS وJavaScript والشعار المضمّن، ولا يحتاج إلى تثبيت حزم.

## الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفي `index.html` و`README.md` إلى الفرع `main`.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/root`.
5. احفظ الإعداد وانتظر إنشاء الرابط.

## تعديل رقم واتساب

افتح `index.html` وابحث عن:

```js
const WHATSAPP_NUMBER = '966500000000';
```

استبدل الرقم برقم متجرك بصيغة دولية بدون علامة `+` أو مسافات.

الصور التجريبية للمنتجات تُحمّل من Unsplash عند توفر الإنترنت، أما شعار ECLAT فهو مضمّن داخل الملف نفسه.
